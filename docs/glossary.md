# プロジェクト用語集 (Glossary)

## 概要

このドキュメントは、toto GOAL3 Predictorプロジェクト内で使用される用語の定義を管理します。

**更新日**: 2025-02-04

## ドメイン用語（toto・サッカー）

### toto GOAL3

**定義**: スポーツ振興くじの一種で、指定された3試合の各チーム（計6チーム）の得点を予測するくじ

**説明**: 各チームの得点を「0点」「1点」「2点」「3点以上」の4カテゴリから選択する。全6チームの予測が的中すると1等当選。

**関連用語**: toto, スポーツ振興くじ, パリミュチュエル方式

**使用例**:
- 「今週のtoto GOAL3の対象試合は横浜FM、川崎、鹿島の3カード」
- 「GOAL3の1等的中確率は4^6 = 4,096分の1」

**英語表記**: toto GOAL3

### 投票率

**定義**: toto購入者全体における各選択肢への投票割合

**説明**: totoONE等のサイトで公開される。投票率が低い選択肢が的中すると配当が高くなる（パリミュチュエル方式）。

**関連用語**: バリュースコア, パリミュチュエル方式

**使用例**:
- 「横浜FMの3点以上の投票率は16%」
- 「投票率が低い選択肢にバリューがある可能性」

**英語表記**: Vote Rate / Betting Rate

### バリュースコア

**定義**: モデル予測確率と公衆投票率の比率（モデル確率 / 投票率）

**説明**: 1.0を超えると期待値がプラスの可能性があり、値が大きいほどバリューが高い。1.5以上で購入検討の目安。

**関連用語**: 投票率, 期待値, Kelly Criterion

**使用例**:
- 「横浜FMの3点以上はバリュースコア1.38でバリューあり」
- 「バリュースコア1.0未満はスキップ」

**計算式**: `バリュースコア = モデル予測確率 / 投票率`

### xG（Expected Goals）

**定義**: 期待得点。シュートの質と位置から算出される得点期待値

**説明**: 1試合あたりのxGが高いほど、多くの得点チャンスを作っていることを意味する。実得点との差（xG Overperformance）は決定力の指標。

**関連用語**: xGA, シュート, 得点

**使用例**:
- 「横浜FMのxGは2.03で、実得点3との差は+0.97」
- 「xGが低いのに得点が多いチームは運に頼っている可能性」

**英語表記**: Expected Goals

### xGA（Expected Goals Against）

**定義**: 被期待得点。相手チームに与えたシュートの質と位置から算出される失点期待値

**説明**: xGAが低いほど守備が堅いことを意味する。

**関連用語**: xG, 失点, 守備

**英語表記**: Expected Goals Against

### PPDA（Passes Per Defensive Action）

**定義**: 守備アクション1回あたりの相手パス数。プレス強度の指標

**説明**: 値が低いほどハイプレスをかけていることを意味する。一般的に10以下がハイプレス、15以上がローブロック。

**関連用語**: プレス, 守備, インターセプト

**使用例**:
- 「PPDAが7.67と低く、積極的にプレスをかけている」
- 「PPDAが高いチームはカウンター狙いの傾向」

**英語表記**: Passes Per Defensive Action

### ボール支配率（Possession）

**定義**: 試合中にボールを保持していた時間の割合（%）

**説明**: 50%を超えるとボールを多く保持していたことを意味する。攻撃的なチームは高くなる傾向があるが、支配率が低くてもカウンターで効率的に得点できるチームもある。

**関連用語**: パス成功率, 攻撃スタイル

**英語表記**: Possession

### シュート決定率（Shot Conversion）

**定義**: シュートから得点に結びついた割合

**計算式**: `決定率 = 得点 / シュート数`

**説明**: 高いほど決定力があることを意味する。一般的に10-15%程度が平均。

**関連用語**: xG, xG Overperformance

**英語表記**: Shot Conversion Rate

### xG Overperformance

**定義**: 実際の得点とxG（期待得点）の差

**計算式**: `xG Overperformance = 実得点 - xG`

**説明**: プラスの場合は決定力が高い（期待値以上に得点）、マイナスの場合は決定力不足または運が悪いことを意味する。長期的には0に収束する傾向。

**使用例**:
- 「xG Overperformance +0.5は、期待値以上に得点できている」

**関連用語**: xG, シュート決定率

## 技術用語（機械学習）

### XGBoost

**定義**: 勾配ブースティング決定木の高速・高精度な実装

**公式サイト**: https://xgboost.readthedocs.io/

**本プロジェクトでの用途**: 得点分布予測のメインモデルとして使用。6クラス（0-5点）の分類問題として学習。

**バージョン**: 2.x

**関連ドキュメント**: docs/functional-design.md#アルゴリズム設計

### Poisson Regression

**定義**: ポアソン分布を仮定した回帰モデル。カウントデータの予測に適する

**本プロジェクトでの用途**: 得点（λ：期待得点数）を予測するベースラインモデル。λからポアソン分布で各得点の確率を算出。

**関連ドキュメント**: docs/functional-design.md#アルゴリズム設計

### キャリブレーション

**定義**: 予測確率を実際の発生確率に近づける補正処理

**本プロジェクトでの用途**: Isotonic RegressionまたはPlatt Scalingを使用して、モデル出力確率を補正。

**関連用語**: Isotonic Regression, Platt Scaling, Brier Score

### Brier Score

**定義**: 確率予測の精度を測る指標。予測確率と実際の結果（0または1）の差の二乗平均

**計算式**: `Brier Score = (1/N) × Σ(予測確率 - 実際の結果)²`

**説明**: 0に近いほど精度が高い。0.25が「常に50%と予測」した場合のスコア。0.20未満が良好とされる。

**本プロジェクトでの用途**: モデル精度の主要KPI（目標: 0.20未満）

**関連用語**: キャリブレーション, カテゴリ的中率

**英語表記**: Brier Score

### カテゴリ的中率

**定義**: 最も確率が高いと予測したカテゴリが実際の結果と一致した割合

**計算式**: `的中率 = (的中数 / 総予測数) × 100%`

**説明**: 4カテゴリ（0点/1点/2点/3点以上）のうち最頻予測の的中率。ランダム予測では約25%。

**本プロジェクトでの用途**: モデル精度の主要KPI（目標: 40%以上）

**関連用語**: Brier Score

### 時系列クロスバリデーション

**定義**: 時系列データに対する交差検証手法。学習データが常に検証データより過去になるよう分割

**説明**: 通常のK-Fold CVと異なり、未来のデータで過去を予測しないよう時間順序を保持。データ漏洩を防ぐ。

**本プロジェクトでの用途**: モデル学習時の検証手法（scikit-learnのTimeSeriesSplit使用）

**関連用語**: 過学習, Cross-Validation

**英語表記**: Time Series Cross-Validation, TimeSeriesSplit

### Isotonic Regression

**定義**: 単調性制約付きの回帰手法。キャリブレーションに使用

**説明**: 予測値と真の確率の関係を単調増加関数で近似。非パラメトリック手法でデータ量が多い場合に有効。

**本プロジェクトでの用途**: モデル出力確率の補正手法（推奨）

**関連用語**: キャリブレーション, Platt Scaling

### Platt Scaling

**定義**: ロジスティック回帰を用いたキャリブレーション手法

**説明**: モデル出力にシグモイド関数を適用して確率を補正。パラメトリック手法でデータ量が少ない場合に有効。

**本プロジェクトでの用途**: モデル出力確率の補正手法（代替）

**関連用語**: キャリブレーション, Isotonic Regression

### Kelly Criterion（ケリー基準）

**定義**: 期待値がプラスの賭けにおいて、資金成長率を最大化する最適ベットサイズを計算する公式

**計算式**: `f* = (p * b - q) / b` （p: 勝率, q: 敗率, b: オッズ-1）

**本プロジェクトでの用途**: 推奨ベットサイズの計算。フルケリーはリスクが高いため、1/4ケリーを使用。

**使用例**:
- 「ケリー基準で計算すると、今回は資金の3%を投入すべき」

## データモデル用語

### Match

**定義**: 1試合を表すエンティティ

**主要フィールド**:
- `id`: 試合の一意識別子（UUID）

## エラー・例外

### DataNotFoundError

**クラス名**: `DataNotFoundError`

**発生条件**: 指定されたチームの試合データが存在しない、または不足している場合

**対処方法**: データをインポートするか、チーム名のスペルを確認

**例**:
```python

```

### ValidationError

**クラス名**: `ValidationError`

**発生条件**: 入力データが不正な場合（形式エラー、範囲外の値など）

**対処方法**: エラーメッセージに従って入力を修正

### ScrapingError

**クラス名**: `ScrapingError`

**発生条件**: 投票率スクレイピングが失敗した場合（ネットワークエラー、サイト構造変更など）

**対処方法**: ネットワーク接続を確認、後で再試行、またはサイト構造の変更を確認

## 計算・アルゴリズム

### バリュースコア計算

**定義**: モデル予測確率と投票率の比率を計算

**計算式**:
```
バリュースコア = モデル確率 / max(投票率, 0.01)
```

**実装箇所**: `src/toto_predictor/services/strategy_engine.py`

**例**:
```
入力: モデル確率=0.22, 投票率=0.16
出力: 0.22 / 0.16 = 1.375
```

### 得点確率分布（ポアソン）

**定義**: ポアソン分布のλ（期待得点）から各得点数の確率を計算

**計算式**:
```
P(k) = (λ^k * e^(-λ)) / k!
```

**実装箇所**: `src/toto_predictor/services/model_ensemble.py`

**例**:
```
入力: λ=1.5
出力: P(0)=0.223, P(1)=0.335, P(2)=0.251, P(3+)=0.191
```
